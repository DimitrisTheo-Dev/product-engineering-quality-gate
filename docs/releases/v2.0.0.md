# v2.0.0 release notes

Version 2 moves setup, tool pins, checks, tiers and waivers into package-local
`quality-gate.config.json`. See the [changelog](../../CHANGELOG.md),
[configuration](../configuration.md) and [v1 migration](../../MIGRATION.md).
